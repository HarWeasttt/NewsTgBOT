# News Telegram Bot

Многофункциональный Telegram бот для автоматического сбора новостей на основе пользовательских промтов.

## Установка

1. Клонируйте репозиторий
2. Установите зависимости: `npm install`
3. Настройте переменные окружения в `.env`
4. Инициализируйте базу данных: `npm run init-plans`
5. Запустите бота: `npm run dev`

## Конфигурация

Заполните все необходимые переменные в файле `.env`

## Функционал

- Автоматический сбор новостей
- Гибкие настройки расписания
- Система подписок
- Панель администратора
